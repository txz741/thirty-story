# 乘风去往回忆里 · GitHub Pages

手机优先的滑动式互动绘本。十个主线故事、加班 IF 和五幕终章已全部接入，没有站点依赖、外部字体、统计脚本或构建步骤。

入口：https://txz741.github.io/thirty-story/ ，样片位于 `demo/`。原占位页保留在 `placeholder.html`。

操作和当前范围详见 [demo/README.md](demo/README.md)。每段回忆自动收藏、Wink 后回到主路；仅加班 IF 需要点击选择。终章按路线展示 10 或 11 枚勋章。

当前操作为手机上划前进、下划回看，刷新重新开始。入包勋章先在空中静置闪光 3 秒，再缩小飞入包里。

五个原创合成音效已经接入，右上角声音按钮提供统一静音和独立音效音量。BGM 接口与独立音量通道已保留，暂未添加音乐。手机可在 [音效试听页](demo/audio-preview.html?v=6) 逐个试听、下载并检查声音解锁。所有声音设置也随刷新恢复默认。

## 发布

仓库 `main` 分支根目录作为 Pages 发布源。此目录中的静态文件整体发布，`.nojekyll` 禁用不必要的 Jekyll 处理。

## 后续更新

修改 `demo/src/`、`demo/styles.css` 或替换 `demo/assets/` 后推送到同一分支即可更新。根地址保持不变，所有素材使用相对路径。

本目录是独立发布内容；项目 handoff、原始照片和设计素材不属于此占位页。
