# 她走过的日子 · GitHub Pages

手机优先的静态占位页。没有依赖、外部字体、统计脚本或构建步骤。

## 发布

将此目录中的 `index.html` 和 `.nojekyll` 放到 GitHub 仓库 `main` 分支根目录。在仓库 Settings → Pages 中选择 Deploy from a branch、`main`、`/(root)`。

## 后续更新

直接编辑 `index.html` 并推送到同一分支，GitHub Pages 会更新页面，地址保持不变。图片或动画可以之后放到 `assets/`，使用相对路径引用，以兼容仓库子路径。

本目录是独立发布内容；项目 handoff、原始照片和设计素材不属于此占位页。
