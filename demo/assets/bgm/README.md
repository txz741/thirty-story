# 四阶段背景音乐

四首 MP3 从用户的 `material/bgm/` 原样复制到本目录，没有重新生成、转码、裁剪或修改。均为 MPEG-1 Layer III、48 kHz、双声道、可变码率。时长为帧扫描近似值，实际播放使用浏览器读取的时长；原始路径与 SHA-256 见 `manifest.json`。

| 原始文件（material/bgm/） | 发布文件（demo/assets/bgm/） | 约时长 | 阶段 |
| --- | --- | --- | --- |
| 1Everyday Adventures.mp3 | 1Everyday Adventures.mp3 | 1:50 | 主路开始，事件 1–4，循环 |
| 2Autumn Afternoon.mp3 | 2Autumn Afternoon.mp3 | 1:30 | 第4事件勋章入包、Wink结束后切换，用于事件5–7，循环 |
| 3Soft Welcome.mp3 | 3Soft Welcome.mp3 | 1:50 | 第7事件勋章入包、Wink结束后切换，包含 IF 与事件9、10，循环 |
| 4Un Voyage Lumineux.mp3 | 4Un Voyage Lumineux.mp3 | 0:55 | 终章第一幕乘风之翼出现，单次播放 |

独立 `src/music-manager.js` 观察故事首次向前推进与最后一次 Wink 完成通知。主路首次出现启动第一首；第4、7事件的最后一枚勋章入包且 Wink 结束，分别升级第二、三首。同一音乐阶段内不重播。红灯事件第4幕首次出现时，第三首用2秒淡出；终章乘风之翼出现时第四首用1秒淡入。回看、IF、立绘切换和重复访问不切回或重播。音乐每次刷新重置。

`src/bgm-player.js` 缓存四个媒体元素和独立增益节点，接入现有 BGM、音效压低与统一静音总线。按用户最新要求采用顺序淡化：旧曲2秒淡出至静音后，新曲才从开头播放并用1秒淡入，不交叉重叠。快速翻入终章时只等待第三首已开始的淡出余量，不重新计时；不阻塞翻页。切换中暂停保存播放位置、淡化剩余时间与待启动曲目。加载失败不影响故事，触摸声音按钮可重试；新曲加载较慢时可能在旧曲淡出后暂时静音。

前三首使用原生循环。终章不循环，在原曲最后 2.5 秒平滑淡出，不剪短原文件；到自然结束后锁定已结束状态，回看、重复进入、静音开关或前后台恢复都不重新启动。只有刷新或明确重置整次体验才清除该状态。

配置：`src/music-config.js` 的 `MUSIC_SETTINGS.fadeOutSeconds=2`、`fadeInSeconds=1` 控制章节顺序淡化；`finaleFadeSeconds=2.5` 保留终章原曲末尾的自然渐弱。`MUSIC_TRACKS` 修改文件与循环设置。`src/audio-config.js` 的默认 BGM 音量 `bgmVolume=.22`、音效 `sfxVolume=.8`；页面滑杆可实时调整，静音开关同时作用于两者。

移动端首次有效触摸时在手势调用栈内解锁 AudioContext 和缓存的媒体元素，避免后续定时切歌失去授权。切后台暂停，回前台尝试恢复；若系统或浏览器阻止自动恢复，页面提示轻触声音按钮。兼容 WebKit 前缀；缺少 cancelAndHoldAtTime 时清理旧自动化并从计算出的当前音量继续，避免曲线重叠。浏览器策略仍须在具体手机上试听确认。
