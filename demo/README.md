# 乘风去往回忆里 · 十个故事完整流程

毕业、蝴蝶结、羽毛球、唱 K、集市大鹅、螃蟹季、下厨、加班、母女吃饭、红灯遇鹅，依次接入，随后进入五幕终章。

手机手指物理向上划前进，下划在事件内部回看；桌面滚轮向下前进、向上回看。主路单向，发现信标后再上划进入分镜。最后一幕继续上划才自动收藏。每枚入包勋章在空中静置 3 秒、边缘闪光后，再平滑缩小沿弧线飞入包里，Wink 后继续走。

仅加班 IF 点击选择。同一次体验中选定现实或 IF 后，下划回看不会重新选择或重复授予。两条路线在同一条主路汇合。IF 额外勋章也单独展示 3 秒。无 IF 终章 10 枚勋章；有 IF 11 枚。乘风之翼只在终章首次出现时授予一次。

选择 IF 后，先看完童年三幕，再直接接现实第四、第五幕，跳过相似的现实第三幕。加班这段共七幕；等现实线也结束后，才依次收藏台灯主勋章与纸飞机稻穗勋章。不选 IF 时仍是原来的完整五幕现实线。

每次刷新从封面重新开始，不读取或保存进度；?debug=1 显示调试入口。终幕保持飞翔画面，再上划不推进，下划可回看。

工程无构建依赖，使用相对资源路径。实际入口 src/journey.js，配置 src/journey-data.js，状态 src/journey-state.js，终章叠层 src/finale.js。

封面开始分批预加载全部分镜（含IF与终章）、人物动作和勋章，并显示准备进度；可以等准备好再上划，也可以先开始。后台通常同时加载两张，为当前翻页保留一个优先通道。加载时显示提示并保留已发出的翻页请求，失败可直接重试。短暂转场最多记住一次新的滑动，步行和收藏动画仍防止重入。BGM保持独立流式播放，音效提前下载，不要求先等全部音乐下载完成。

本轮按已认可的做法保持临时主路、包口光效和静态封面；正式背景、局部包盖、步态精修和封面降落动画后续调整。未重新生成人物或插画。

六个音效已分别绑定发现节点、进入回忆、勋章起飞、成功入包、终章飞出与汇聚。勋章仍先展示 3 秒，然后才播放飞行声，入包完成后播放收藏三音符。声音从真实触摸或按键后解锁；切到后台暂停，回到前台尝试从原进度恢复，若浏览器拦截，轻触声音按钮重试。

右上角声音按钮提供统一静音、独立音效音量（默认80%）与 BGM 音量（22%）。四阶段对应关系不变：主路开始播放第一首，第4／7事件最后一枚勋章入包且 Wink 结束后，保留当前音乐再走4步；随后画面完整淡出至纯白、旧曲同步淡出，持续2秒；下一乐章与新曲1秒淡入。白色层覆盖整个视口和声音按钮，期间点击与滑动无效，也不会排队到下一乐章。红灯事件第4幕提前用2秒淡出第三首，乘风之翼出现时用1秒淡入第四首。阶段只升级，IF、同阶段事件与回看不重播。前三首循环，第四首单次、原曲末尾渐弱后静音。设置见 `src/music-config.js` 与 `src/audio-config.js`，详见 [背景音乐说明](assets/bgm/README.md) 与 [四阶段试听页](music-preview.html?v=21)。

[音效试听与手机解锁自检](audio-preview.html?v=21) 可逐个或连续试听六个 WAV、下载文件，并在本机临时选择音乐验证 BGM 通道。选择的本机文件不会上传。音效规格、触发规则和再生成方式见 [音频说明](assets/audio/README.md)。

本轮新增三秒勋章柔光星声。终章包中仅飞出前九个事件的 9／10 枚回忆勋章，乘风之翼单独亮相；汇聚页先展示中心约一秒，再由画面下方依次飞入其他勋章，全部到位后用 32 秒转一圈，图案保持正向。减少动态效果模式显示静态排列。可在 [勋章与终章动画预览](effects-preview.html?v=21) 直接选择场景、切换 IF、重播或暂停环绕。

v8 根据手机反馈增强展示时的边缘呼吸：细亮边、金色光晕和外层柔光共同起伏，明暗与扩散范围拉开；仍在三秒内完成两次平滑呼吸，音效和起飞时机不变。

v9 接入动作06开包立绘：三秒展示与起飞使用动作05，勋章接近包口时切到06，实际入包后立即切到 Wink 并播放收藏音效。普通与 IF 隐藏勋章都执行该顺序，06 提前加载，终点对准打开后的包口。可 [直接预览收藏动作](effects-preview.html?v=21&scene=badge)。

第一乐章现使用带稀疏花草装点的长屏地图，事件依次位于右、左、右、左；起点与前两步不出现毕业场景。K歌后补足四步退场道路。第二、三乐章长图已接入：第二乐章使用奶油杏金道路与秋叶草穗，第三乐章使用雾蓝紫道路与银白花草；节点均按各自长图的右、左、右分布。每次乐章交接的四步走完才淡出，不在 Wink 后立即切曲。

最终谢幕在终章第5幕自动出现：演职员表依次为导演／编剧／主演文邹邹、客串妈妈与大鹅，1秒后开始18秒上滚；完全离场后，`Still On The Way ...` 从下方用3.2秒升至屏幕中央，停留并以4.6秒周期柔和呼吸。米白衬线字配淡紫阴影，字号随插图宽度调整。继续前滑到结束态、重复加载和旋转屏幕均不重播；回看上一幕再进入最后一幕时重播。后台暂停谢幕，减少动态效果时显示静态演职员表后淡入英文。[直接预览最终谢幕](effects-preview.html?scene=4&v=21)。

最终谢幕背景已替换为用户提供的约10秒视频，网页资源为 `assets/stories/finale/05.mp4`（720×1280、24fps、H.264 MP4，约3.35MB）。导出时已移除音轨，并固定静音、内联播放。封面开始预加载，进入终章第5幕时播放一次，结束后保留末帧，演职员表与英文字幕仍按原节奏继续；回看后重进会从头播放，进入结束态或旋转屏幕不重置，切后台暂停。原JPG仅作加载或失败时的后备画面；若浏览器拦截自动播放，可轻触播放画面，绘本滑动不受影响。
