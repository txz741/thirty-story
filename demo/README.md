# 乘风去往回忆里 · M1 交互样片

此版本接入真实封面、人物素材、羽毛球四幕及对应勋章。

## 体验

手机手指向屏幕下方划＝前进；向上划＝事件内回看。桌面使用滚轮，下＝前进、上＝回看。不是原生网页长页面滚动。

封面 → 主路 → 四次独立的行走手势 → 自动停下疑惑 → 新的一次向下手势 → 羽毛球四幕 → 最后一幕继续向下 → 自动收藏、Wink → 回到主路。

主路和事件第一幕不允许后退。收藏过程不需要点击，且无法重复领取。刷新会保留进度；在地址末尾加 `?debug=1` 可查看状态并重置进度。

- 分镜始终等比完整呈现，不裁剪人物与关键道具。开场使用静态封面与轻淡入，未做大鹅降落动画。

无需构建即可静态托管。`src/story-data.js` 管理分镜文字与资源路径。所有路径均相对于当前目录，兼容 GitHub Pages 子目录。
