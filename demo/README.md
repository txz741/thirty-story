# 乘风去往回忆里 · 十个故事完整流程

毕业、蝴蝶结、羽毛球、唱 K、集市大鹅、螃蟹季、下厨、加班、母女吃饭、红灯遇鹅，依次接入，随后进入五幕终章。

手机手指物理向上划前进，下划在事件内部回看；桌面滚轮向下前进、向上回看。主路单向，发现信标后再上划进入分镜。最后一幕继续上划才自动收藏。每枚入包勋章在空中静置 3 秒、边缘闪光后，再平滑缩小沿弧线飞入包里，Wink 后继续走。

仅加班 IF 点击选择。同一次体验中选定现实或 IF 后，下划回看不会重新选择或重复授予。两条路线在同一条主路汇合。IF 额外勋章也单独展示 3 秒。无 IF 终章 10 枚勋章；有 IF 11 枚。乘风之翼只在终章首次出现时授予一次。

选择 IF 后，先看完童年三幕，再直接接现实第四、第五幕，跳过相似的现实第三幕。加班这段共七幕；等现实线也结束后，才依次收藏台灯主勋章与纸飞机稻穗勋章。不选 IF 时仍是原来的完整五幕现实线。

每次刷新从封面重新开始，不读取或保存进度；?debug=1 显示调试入口。终幕保持飞翔画面，再上划不推进，下划可回看。

工程无构建依赖，使用相对资源路径。实际入口 src/journey.js，配置 src/journey-data.js，状态 src/journey-state.js，终章叠层 src/finale.js。

本轮按已认可的做法保持临时主路、包口光效和静态封面；正式背景、局部包盖、步态精修和封面降落动画后续调整。未重新生成人物或插画。

六个音效已分别绑定发现节点、进入回忆、勋章起飞、成功入包、终章飞出与汇聚。勋章仍先展示 3 秒，然后才播放飞行声，入包完成后播放收藏三音符。声音从真实触摸或按键后解锁；切到后台暂停，回到页面后再次触摸恢复。

右上角声音按钮提供统一静音、音效音量和预留的 BGM 音量。当前没有 BGM 文件，音乐音量控件暂时禁用。在 `src/audio-config.js` 的 `AUDIO_DEFAULTS.bgmSrc` 填入相对路径即可启用，无需改动画；也可通过 `audio.setBgmSource(src)` 在运行时设置。声音设置不会保存。

[音效试听与手机解锁自检](audio-preview.html?v=7) 可逐个或连续试听六个 WAV、下载文件，并在本机临时选择音乐验证 BGM 通道。选择的本机文件不会上传。音效规格、触发规则和再生成方式见 [音频说明](assets/audio/README.md)。

本轮新增三秒勋章柔光星声。终章包中仅飞出前九个事件的 9／10 枚回忆勋章，乘风之翼单独亮相；汇聚页先展示中心约一秒，再由画面下方依次飞入其他勋章，全部到位后用 32 秒转一圈，图案保持正向。减少动态效果模式显示静态排列。可在 [勋章与终章动画预览](effects-preview.html?v=7) 直接选择场景、切换 IF、重播或暂停环绕。
