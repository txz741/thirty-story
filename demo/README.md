# 乘风去往回忆里 · 十个故事完整流程

毕业、蝴蝶结、羽毛球、唱 K、集市大鹅、螃蟹季、下厨、加班、母女吃饭、红灯遇鹅，依次接入，随后进入五幕终章。

手机手指物理向上划前进，下划在事件内部回看；桌面滚轮向下前进、向上回看。主路单向，发现信标后再上划进入分镜。最后一幕继续上划才自动收藏。每枚入包勋章在空中静置 3 秒、边缘闪光后，再平滑缩小沿弧线飞入包里，Wink 后继续走。

仅加班 IF 点击选择。同一次体验中选定现实或 IF 后，下划回看不会重新选择或重复授予。两条路线在同一条主路汇合。IF 额外勋章也单独展示 3 秒。无 IF 终章 10 枚勋章；有 IF 11 枚。乘风之翼只在终章首次出现时授予一次。

选择 IF 后，先看完童年三幕，再直接接现实第四、第五幕，跳过相似的现实第三幕。加班这段共七幕；等现实线也结束后，才依次收藏台灯主勋章与纸飞机稻穗勋章。不选 IF 时仍是原来的完整五幕现实线。

每次刷新从封面重新开始，不读取或保存进度；?debug=1 显示调试入口。终幕保持飞翔画面，再上划不推进，下划可回看。

工程无构建依赖，使用相对资源路径。实际入口 src/journey.js，配置 src/journey-data.js，状态 src/journey-state.js，终章叠层 src/finale.js。

本轮按已认可的做法保持临时主路、包口光效和静态封面；正式背景、局部包盖、步态精修和封面降落动画后续调整。未重新生成人物或插画。

六个音效已分别绑定发现节点、进入回忆、勋章起飞、成功入包、终章飞出与汇聚。勋章仍先展示 3 秒，然后才播放飞行声，入包完成后播放收藏三音符。声音从真实触摸或按键后解锁；切到后台暂停，回到前台尝试从原进度恢复，若浏览器拦截，轻触声音按钮重试。

右上角声音按钮提供统一静音、独立音效音量与 BGM 音量。四首 BGM 按主路开始、第五事件、第八事件和终章乘风之翼亮相切换，阶段只升级，IF 与回看不切换。前三首循环，终章只播放一次，末尾渐弱后静音。文件与淡化时间在 `src/music-config.js` 修改；默认音量在 `src/audio-config.js` 修改，也可直接使用页面滑杆。声音设置不会保存。详见 [背景音乐说明](assets/bgm/README.md) 与 [四阶段试听页](music-preview.html?v=10)。

[音效试听与手机解锁自检](audio-preview.html?v=10) 可逐个或连续试听六个 WAV、下载文件，并在本机临时选择音乐验证 BGM 通道。选择的本机文件不会上传。音效规格、触发规则和再生成方式见 [音频说明](assets/audio/README.md)。

本轮新增三秒勋章柔光星声。终章包中仅飞出前九个事件的 9／10 枚回忆勋章，乘风之翼单独亮相；汇聚页先展示中心约一秒，再由画面下方依次飞入其他勋章，全部到位后用 32 秒转一圈，图案保持正向。减少动态效果模式显示静态排列。可在 [勋章与终章动画预览](effects-preview.html?v=10) 直接选择场景、切换 IF、重播或暂停环绕。

v8 根据手机反馈增强展示时的边缘呼吸：细亮边、金色光晕和外层柔光共同起伏，明暗与扩散范围拉开；仍在三秒内完成两次平滑呼吸，音效和起飞时机不变。

v9 接入动作06开包立绘：三秒展示与起飞使用动作05，勋章接近包口时切到06，实际入包后立即切到 Wink 并播放收藏音效。普通与 IF 隐藏勋章都执行该顺序，06 提前加载，终点对准打开后的包口。可 [直接预览收藏动作](effects-preview.html?v=10&scene=badge)。
